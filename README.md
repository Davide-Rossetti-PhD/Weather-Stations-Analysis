# Weather Stations Data Analysis

This project analyzes daily meteorological data collected from multiple weather stations.  
It computes rainfall and temperature statistics, identifies extreme values, and visualizes the results.

## Overview
Accurate weather data analysis is essential for understanding climate variability and extreme conditions.  
This Python project demonstrates how to process structured weather data, compute descriptive statistics, and produce visualizations.

### Features
- Extracts station identifiers and builds structured matrices
- Computes rainfall statistics (min, max, mean, std)
- Finds the station with the highest temperature each day
- Identifies the coldest day in the dataset
- Visualizes rainfall trends with Matplotlib
